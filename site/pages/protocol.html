02 · Protocol

From gesture
to bytes.

Oasis extends Bluetooth Mesh with a vendor model and a compact command family. The useful part is not just the opcode—it is the sequence, payload shape, and transport context.

Company 0x02E5Model 0x02E5C00AProxy 0x1828

The Mesh identity

Provisioning uses Bluetooth service 0x1827; normal proxy traffic uses 0x1828. Lighting commands target the Oasis vendor model 0x02E5C00A, owned by company identifier 0x02E5.

Reading the map

“Confirmed” means the payload is supported by direct observation or multiple independent code paths. “Decoded” means static software evidence is strong but live coverage may be narrower.

Sequence matters

A color is two commands.

CC 01          # enter RGB mode
C6 RR GG BB    # apply 24-bit color

CC 02          # enter white-temperature mode
D2 KK KK PP…   # Kelvin + brightness + timestamp

Mode selection is not decorative metadata. It tells the device which rendering engine should interpret the next light payload.

What the bridge refuses to expose

Factory reset, provisioning-mode changes, network credentials, and room membership are outside the everyday controller. Keeping those paths out of the UI limits the blast radius of a bug.
